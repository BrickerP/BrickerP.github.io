# 03 — Problem

## Look inward

The current work is already a coherent 48-second first-person loop. Rebuilding
the route would confuse novelty with identity. The missing layer is visible
authorship: the card says `LOOP 01`, but the runtime still presents an older,
standalone artwork vocabulary.

## Look outward

A Profile visitor arrives from a small static card. They should immediately
understand that the full-screen world is the same artifact, not an unrelated
WebGL demo. On mobile, they should see the identity and horizon without controls
fighting for the same top band.

## Jobs to be done

- **Functional:** enter, pause, record, fullscreen, and inspect the artist.
- **Social:** recognize a distinctive personal artifact worth sharing.
- **Emotional:** feel a calm authored circuit and notice its impossible return.

## Proto-persona — hypothesis

- Visitor: an AI builder, creative technologist, or collaborator arriving from
  the GitHub Profile.
- Trigger: the LOOP card promises an enterable 48-second Beijing world.
- Current workaround: infer the relationship from the shared title.
- Success moment: the road carrier and closure node make the connection
  self-evident before the visitor opens About.

## Problem statement

The live animation's route and interactions are complete, but its visible
identity is weaker than the card that introduces it, especially on mobile.

## Observable success

- `LOOP 01` is the first identity read.
- Exactly one signature vermilion scene node exists.
- Desktop and portrait preserve a clear title, horizon, and action rail.
- A static reduced-motion frame looks intentional and belongs to the card.
- Browser, recording, seam, performance, and accessibility gates remain green.
