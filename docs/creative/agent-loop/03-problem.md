# Agent loop — Problem

Status: draft, 2026-10-05. Not an approval to code.

## Problem

A visitor who has seen a current code film does not read LOOP 01 as a
finished image. The 48-second Beijing drive is already a designed sequence.
The picture is a flat-shaded diorama, so the design never arrives as a still.

## Not the problem

- The README needs a new layout.
- The site needs a second film or a game.
- The twelve place-names are wrong.
- The page needs more buildings.

## Quality, said plainly

LOOP 01 is not the best image work in this field. Threejs-Punk and ABYSSAL
are ahead on light, materials, and atmosphere. LOOP 01 is ahead of those
demos on editing: one closed minute, one hero at a time, no HUD, a written
spatial contract. The gap to close is the image, without giving up that
editing.

A kit of repeated blocks with bloom would lose the editing and still miss
their image. That result is worse than the current film.

## Success a person can see

Pause on each four-second boundary. The frame is a poster: one subject, one
light direction, one vermilion note, a clear way through. Play the whole
48 seconds and the twelfth passage returns to the first frame. A later
passage can be added by registering a module, not by growing
`BeijingDriveScene.ts`.
